# CodeAlpha Internship

## Task 2: Basic Network Sniffer

### Project Title

Basic Network Sniffer Using Python and Scapy

### Project Description

This project is a basic network sniffer developed using Python and the Scapy library. The program captures network packets visible to the local host and displays important information about each packet.

### Objectives

* Capture network packets.
* Identify network protocols.
* Display source and destination IP addresses.
* Display packet size.
* Understand basic network traffic monitoring.

### Technologies Used

* Python 3
* Scapy
* Npcap
* Windows

### Features

* Displays Source IP address.
* Displays Destination IP address.
* Identifies TCP, UDP and ICMP protocols.
* Displays packet length in bytes.

### How to Run

1. Install Python.
2. Install Scapy using `pip install scapy`.
3. Install Npcap on Windows.
4. Open Command Prompt.
5. Go to the project folder.
6. Run `python sniffer.py`.

### Result

The Basic Network Sniffer successfully captured and displayed network packets visible to the host.

### Conclusion

This project provided practical knowledge about network packet capture, IP addresses, protocols and packet sizes using Python and Scapy.
